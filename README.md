# 🎵 Mood Sync Player

### *What happens when software starts paying attention to human emotion?*

This project explores **affective computing** through a webcam-based music experience.

```text
📷 Webcam
   ↓
👤 Face Detection
   ↓
🧠 Emotion Detection
   ↓
🎭 Mood Classification
   ↓
🎵 Playlist Selection
   ↓
🔄 Dynamic Music Experience
```

Built with:

* HTML5
* CSS3
* JavaScript
* face-api.js
* TensorFlow.js
* Web APIs

The project detects facial expressions directly in the browser and changes the music experience according to the detected emotional state.

### Hackathon Story

One of the most fun builds in my journey started almost accidentally: a webcam-based mood music player built rapidly during a GITAM hackathon.

The project went from:

**“Let's build something random.”**

to

**“Wait... this actually works.”**

The prototype used facial landmarks and ML-based expression detection to drive the music experience.

🔗 **Repository:** https://github.com/MDJ1209/ML.based_Music-player

# 🏥 Intelligent Queue Orchestration

A healthcare-focused queue management concept designed for hospitals and clinics.

### The problem

Traditional hospital queues can treat every patient almost identically.

But healthcare isn't always:

```text
First Come → First Served
```

Sometimes:

```text
Emergency
   ↓
High Priority
   ↓
Regular
```

The system explored intelligent token management and logic-based prioritization to improve patient flow.

This work also became part of my participation in the **NSRIT Startup Ideathon**, where our team secured **1st Prize** and I served as **Team Lead**, guiding research, pitch development and the live presentation.

---

The work involved identifying **27 vulnerabilities**, contributing to a **40% reduction in critical vulnerabilities**, and producing SQL-based dashboards and remediation documentation for engineering teams.
